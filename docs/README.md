# Engineering Documentation

This folder contains a browsable static documentation page for the MCP Server List project.

## Open locally

- Open [docs/index.html](index.html) directly in VS Code
- Or use a browser preview extension in VS Code to render the file
- The page is static HTML and requires no build step or dependency installation

## Contents

- Product overview
- Technical architecture
- Applied design patterns
- Lifecycle and execution flow
- UI/UX assessment and product direction
- Recommended next steps
- UI Expert Analysis review
